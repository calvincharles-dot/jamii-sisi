# JAMII&SISI — Starter ya tovuti

Huu ni mwanzo wa tovuti ya JAMII&SISI yenye:
- Ukurasa wa wateja na katalogi ya bidhaa.
- Sehemu tofauti ya Admin inayoingia kwa Supabase Auth.
- Kuongeza na kufuta bidhaa kupitia Admin.
- Ruhusa za database zinategemea RLS na jedwali `admin_users`.

## Muhimu kabla ya kuitumia
1. Fungua `app.js`.
2. Badilisha `WEKA_SUPABASE_PROJECT_URL` na Project URL yako.
3. Badilisha `WEKA_SUPABASE_PUBLISHABLE_KEY` na Publishable Key yako.
4. Tumia publishable key pekee. USIWEKE `sb_secret` au `service_role` key kwenye faili hizi.

## Kile ambacho bado hakijajengwa
Huu si mfumo kamili wa uzalishaji. Bado hakuna:
- Malipo ya moja kwa moja na uthibitisho wa webhook.
- Upakuaji salama wa premium baada ya malipo.
- Upload ya faili kupitia dashboard.
- Fomu kamili ya oda za huduma.
- Uhakiki wa usalama wa mwisho na majaribio ya uzalishaji.

Usiweke faili za premium kwenye public bucket. Usitoe premium download link kwa umma.
